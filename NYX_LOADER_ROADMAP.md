# 🚀 nyx.loader — Мастер-план и архитектурная дорожная карта

> **Контекст экосистемы**:
> - `https://nyxsile.lol` — личный сайт-карточка создателя экосистемы.
> - `https://nyx.sideload.space` — основной портал, где разворачивается вся активность, обновления и дистрибуция.
> - **nyx.sign** (отдельный будущий проект) — получит веб-каталог приложений и гибридный режим подписи (P12 + Private cert + DNS).
> - **nyx.loader** — нативный, легковесный десктопный сайдлоадер-компаньон (Tauri + Rust + React/TS) для macOS и Windows.

---

## 1. Концепция и цель nyx.loader

**nyx.loader** — это скоростной нативный десктопный сайдлоадер в фирменном неоновом стиле `nyx`, который сохраняет легендарную легковесность iLoader для работы даже на старых ПК:
1. **Обход лимита 3 приложений**: готовый сценарий автонастройки LiveContainer.
2. **Simple Mode (для слабых ПК)**: встроенный легковесный режим без холста звёзд и тяжёлых размытий GPU с автодетектированием и аварийным экраном восстановления.
3. **Безопасная подпись Apple ID**: бесплатный аккаунт на 7 дней через Anisette без передачи паролей третьим лицам.
4. **Управление сопряжением**: экспорт и управление файлами Pairing для SideStore и WireGuard.
5. **Родной статусник iLoader**: надёжный пошаговый трекинг операций без усложнения UI.

## 2. Архитектура исходного iLoader (`nab138/iloader`)

Проект построен на **Tauri v2** (React + Vite + TypeScript на фронте, Rust на бэкенде):

```text
iloader/
├── src-tauri/                   # 🦀 Rust бэкенд (системные вызовы, USB, Apple API)
│   ├── src/
│   │   ├── main.rs              # Точка входа Tauri, регистрация команд
│   │   ├── lib.rs               # Экспорт invoke-хендлеров
│   │   ├── account.rs           # Авторизация Apple ID (SRP, Anisette, 2FA, сессии)
│   │   ├── device.rs            # Работа с iPhone по USB (usbmuxd, libimobiledevice)
│   │   ├── pairing.rs           # Сопряжение устройств, генерация pairing-файлов
│   │   ├── sideload.rs          # Распаковка IPA, генерация provisioning, подпись, установка
│   │   ├── operation.rs         # Очередь асинхронных операций установки
│   │   ├── secure_storage.rs    # Безопасное хранение токенов и паролей в Keychain/Credential Manager
│   │   └── logging.rs           # Логирование процесса установки
│   ├── Cargo.toml               # Зависимости Rust (tauri, reqwest, plist, openssl, aes, zip)
│   └── tauri.conf.json          # Конфигурация окна, бандла, прав и метаданных приложения
│
├── src/                         # ⚛️ React + TypeScript фронтенд
│   ├── App.tsx                  # Главный лэйаут, навигация, драг-н-дроп IPA
│   ├── Device.tsx               # Панель подключенного устройства (UDID, заряд, модель, приложения)
│   ├── AppleID.tsx              # Окно авторизации в Apple ID и управление сертификатами
│   ├── pages/                   # Страницы и модалки
│   ├── components/              # Кнопки, инпуты, диалоги, списки
│   ├── locales/                 # Локализация i18next (JSON-словари)
│   ├── main.tsx                 # Точка входа React
│   └── App.css                  # Базовые стили
│
├── package.json                 # Node/Bun зависимости
└── vite.config.ts               # Конфигурация Vite
```

## 3. Модули для реализации в `nyx.loader`

### Модуль 1: Фирменный дизайн и Simple Mode
- **Неоновый стиль `nyx`**:
  - Палитра: глубокий космический фон (`#0A0A0F`), акцентные фиолетовые и бирюзовые неоновые градиенты (`#7B61FF`, `#38BDF8`).
  - Фоновый анимированный Canvas со звёздами (`StarsBackground`).
- **Сверхлегкий Simple Mode**:
  - Мгновенное отключение Canvas и `backdrop-filter: blur(...)` для нулевой нагрузки на старые процессоры и встроенную графику.
  - Автодетектирование слабых ПК (`hardwareConcurrency <= 2`, `prefers-reduced-motion`).
  - Аварийный сторожевой экран (Crash Guard / Recovery) с возможностью запуска в 1 клик.
  - Хоткей быстрого переключения (`Shift+S`).

### Модуль 2: Надёжный трекинг операций (Родной статусник iLoader)
- **Сохранение проверенной архитектуры**:
  - Полнофункциональный компонент `OperationView.tsx` с пошаговой индикацией процесса установки, проверками, логами и кнопками повтора.
  - Без лишних визуальных нагромождений, быстрый и отзывчивый.

### Модуль 3: Умный сетап LiveContainer (Обход лимита 3 приложений)
- **Суть фичи**:
  - Бесплатный Apple ID разрешает только 3 приложения на 7 дней.
  - LiveContainer позволяет запускать неограниченное число приложений внутри одного контейнера.
  - В софте создается сценарий «Мастер LiveContainer»:
    1. Автоматическая подпись и установка LiveContainer на телефон.
    2. Установка сертификатов сопряжения и помощь с JIT.
    3. Предустановка ESign внутрь контейнера.

### Модуль 4: Генератор и экспорт Pairing File для SideStore
- **Суть фичи**:
  - SideStore для работы VPN/WireGuard требует файл `.mobiledevicepairing`.
  - Софт находит актуальный Pairing Record для подключенного устройства в системном хранилище Lockdown (`/var/db/lockdown` на macOS или `%ProgramData%\Apple\Lockdown` на Windows).
  - Предоставляет кнопку «Экспортировать файл сопряжения» (AirDrop / сохранение файлом).

> 💡 **Примечание**: Каталог приложений (`Store`), установка DNS-профилей и гибридная подпись (P12 + Private cert) выделены в отдельный проект **`nyx.sign`**, чтобы не перегружать легковесный клиент `nyx.loader`.

## 4. Пошаговый план разработки (Roadmap)

### Этап 1: Брендинг и настройка проекта ✅ (ВЫПОЛНЕНО)
- Настройка `tauri.conf.json` (`nyx.loader`, `lol.nyxsile.loader`).
- Генерация полного комплекта иконок для macOS и Windows.
- Переименование в `package.json` и `index.html`.

### Этап 2: Трансформация интерфейса и Simple Mode ✅ (ВЫПОЛНЕНО)
- Тема `nyx-theme.css`, стеклянные карточки и неоновые акценты.
- Компонент `StarsBackground`.
- Продвинутый **Simple Mode**: отключение эффектов, сохранение состояния, хоткей `Shift+S`, автоопределение.
- Двухуровневый аварийный экран восстановления (AppErrorBoundary + index.html Watchdog).

### Этап 3: Полировка функционала загрузчика (LiveContainer & Pairing) ⏳
- Улучшение сценария установки LiveContainer (пресет стабильный/nightly).
- Экспорт Pairing File (`.mobiledevicepairing`) в один клик.
- Подключение ссылки на основной портал `https://nyx.sideload.space`.

### Этап 4: Подготовка к релизной сборке
- Очистка от неиспользуемых зависимостей.
- Сборка бинарников под macOS (DMG) и Windows (MSI/EXE).

### Этап 5: Сборка и релиз
1. Установка окружения:
   ```bash
   brew install rustup
   rustup-init -y
   npm install
   ```
2. Тестовый запуск:
   ```bash
   npm run tauri dev
   ```
3. Сборка релизного Universal DMG для macOS:
   ```bash
   npm run tauri build
   ```
